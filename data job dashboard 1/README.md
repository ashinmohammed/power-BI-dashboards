# 📊 Data Job Dashboard | Power BI

An interactive Power BI dashboard built to explore the data job market. This project was created as my **first Power BI dashboard** to practice designing reports, working with different visualizations, and creating interactive dashboards.

The report contains two pages:
- **Main Dashboard** – Overall analysis of the data job market
- **Drill-through Dashboard** – Detailed analysis for individual job titles

# 📌 Project Overview

This dashboard provides insights into:

- Total number of job postings
- Average yearly salary
- Average hourly salary
- Monthly job trends
- Job counts by job title
- Salary comparison across different roles
- Degree requirements
- Work-from-home availability
- Top hiring platforms
- Countries with the highest number of job postings

The report includes slicers and drill-through functionality, allowing users to explore specific job roles in more detail.

---
# 📊 Key Insights

Some insights obtained from the dashboard include:

- Data Engineer has the highest number of job postings.
- Senior Data Scientist offers one of the highest salaries.
- A significant percentage of jobs do not require a degree.
- LinkedIn is the leading hiring platform.
- North America contributes the highest number of data job postings.

## Drill-through Dashboard

For each selected job title, the dashboard displays:

- Average Yearly Salary
- Average Hourly Salary
- Median Salary vs Average Salary Gauge
- Degree Requirement Distribution
- Work From Home Distribution
- Highest Hiring Platforms
- Top Countries Hiring
