# 📊 Data Jobs Dashboard 2 | Power BI

An interactive **Power BI dashboard** that analyzes the data job market, helping users explore the most in-demand skills, salary trends, and job opportunities across different countries.

This project focuses on creating an interactive user experience by combining **Power Query**, **DAX Measures**, **Field Parameters**, and **Bookmarks**.

# 📌 Project Overview

This dashboard enables users to explore the data jobs market through interactive visualizations and dynamic filtering.

Users can:

- View the most demanded technical skills.
- Compare salaries across different data-related job roles.
- Filter results by Job Title and Country.
- Switch between different metrics using field parameters.
- Interact with a custom slide-out filter panel built using bookmarks.

---
# 📈 Key Insights

- **Python** is the most in-demand skill, appearing in approximately **64%** of job postings.
- **SQL** is the second most requested skill, making it one of the core requirements for data-related roles.
- **Senior Data Scientist** has the highest median yearly salary, followed closely by **Senior Data Engineer**.
- **Cloud Engineer** offers the highest **median hourly salary**, earning approximately **$65 per hour**.
- The dataset contains approximately **479K** job postings, providing a broad view of the data job market.
- On average, employers expect candidates to possess **4–5 technical skills** for a single job role.

### 🎛 Interactive Features

#### 🔹 Bookmark-Based Filter Panel

A custom filter panel opens when clicking the filter icon in the top-right corner.

The panel allows users to filter the report by:

- Job Title
- Country

The panel was created using **Power BI Bookmarks**, providing a clean and user-friendly experience without permanently displaying slicers.

---

#### 🔹 Field Parameters

Users can dynamically switch between:

### Skill Chart

- Job Count
- Job Count %

### Salary Chart

- Median Yearly Salary
- Median Hourly Salary

This allows multiple insights to be displayed using a single visual.

# ⚡ Power BI Features Implemented

### Data Preparation

- Data Cleaning using Power Query
- Removing unnecessary columns
- Formatting data types

### DAX

Created DAX measures for:

- Job Count
- Skills per Job
- Median Yearly Salary
- Median Hourly Salary
- Percentage calculations

### Field Parameters

Implemented field parameters to allow users to dynamically switch between:

- Job Count ↔ Job Count %
- Median Yearly Salary ↔ Median Hourly Salary

### Bookmarks

Created a custom slide-out filter panel using bookmarks and buttons to improve dashboard usability.
